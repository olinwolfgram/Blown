# Blown Wing Cesium Playback

This viewer replays flight-history CSVs generated by the control demos.

## Recommended CSV sources

The easiest way to generate logs for the viewer is to run the 10-motor LQR closed-loop demos:

```powershell
python scripts/demo_longitudinal_closed_loop_10motor.py
python scripts/demo_lateral_closed_loop_10motor.py
```

Those scripts write timestamped files into:

- `outputs/flight_history/`

Example filenames:

- `*_longitudinal_lqr_10motor_flight.csv`
- `*_lateral_lqr_10motor_flight.csv`

## What the viewer reads

The CSV parser looks for:

- `time_s`
- `lat_deg`, `lon_deg`, `alt_m`
- `east_m`, `north_m`, `up_m`
- `roll_deg`, `pitch_deg`, `yaw_deg`, `heading_deg`
- `u_mps`, `v_mps`, `w_mps`
- `p_deg_s`, `q_deg_s`, `r_deg_s`
- `rpm_left`, `rpm_right`, `collective_rpm`
- `rpm_1` through `rpm_10`
- `elevator_deg`, `aileron_deg`, `rudder_deg`, `flap_deg`

If local ENU offsets are present, the same trajectory can be replayed from any origin selected in the GUI.

## How to run

Start the local static server from the repository root:

```powershell
python blown_sim/serve.py
```

Then in the browser:

1. paste a Cesium Ion token,
2. optionally adjust the latitude / longitude / altitude origin,
3. select a CSV from `outputs/flight_history/`,
4. press `Visualize Flight`.

## Sidebar controls

The sidebar includes a `Live Controls` section with:

- ten motor bars labeled `M1` through `M10`,
- live actuator deviation values,
- trim/reference values shown at the bar centers,
- surface bars for elevator, aileron, rudder, and flap when present.

Motor bars are centered on the trim RPM reference, not on zero RPM.

## Default origin

The default replay origin is Lake Lagunita, Stanford:

- latitude `37.423273`
- longitude `-122.176076`
- altitude `40.0 m`

## Tuning constants

Useful playback constants live near the top of:

- `blown_sim/app.js`

Notable constants:

- `MODEL_HEADING_CORRECTION_DEG`
- `MODEL_PITCH_CORRECTION_DEG`
- `MODEL_ROLL_CORRECTION_DEG`
- `PROP_VISUAL_RPM_SCALE`
- `PROP_ROTATION_AXIS`

These control model orientation and propeller spin appearance during playback.
